# Project Page

This directory is the static GitHub Pages site for the anonymous code release.
It uses the Academic Project Page Template structure: `index.html` plus
template assets under `static/`.

Recommended GitHub Pages setting:

```text
Settings -> Pages -> Build and deployment
Source: Deploy from a branch
Branch: main
Folder: /docs
```

After GitHub finishes deployment, use the URL shown by the GitHub Pages
settings page. For a project repository it usually has the form:

```text
https://<anonymous-username>.github.io/<repository-name>/
```
